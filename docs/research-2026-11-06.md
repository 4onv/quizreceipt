# Why QuizReceipt

Research covers **November 6, 2026 in America/Chicago**, from `2026-11-06T06:00:00Z` through, but excluding, `2026-11-07T06:00:00Z`. Sources were reviewed on November 7.

QuizReceipt was selected to make technical quizzes easier to inspect after grading. The intended focus is literal answer choices, explanations for each option, and an exported attempt tied to the exact quiz content so a local command can recompute its result.

## Three ideas compared

Scores are editorial estimates from 1 to 5, with 5 strongest. They support a scope decision and provide no prediction of stars.

| Idea | Demand | Distinct value | Demo ease | Discoverability | Decision |
| --- | --- | --- | --- | --- | --- |
| QuizReceipt | 4 | 3 | 5 | 4 | Selected around content-bound receipt verification and exact technical labels |
| Shell argument diagnostic worksheet | 4 | 2 | 4 | 3 | Deferred because argument visualizers and process inspectors already cover much of the workflow |
| PromQL matcher-change preview | 4 | 3 | 3 | 3 | Deferred because faithful query parsing expands the first release substantially |

**QuizReceipt** can demonstrate all three grading states in a small offline file. A developer can then check the exported answers against the matching quiz locally. Technical educators and people generating lessons with agents are a plausible audience. Existing quiz builders cover most presentation features, so the receipt workflow is central to the selection.

**Argument diagnostics** address two November 6 reports about Python paths with spaces receiving literal quote characters, filed at 07:48:53 and 10:03:38 UTC. Both were closed and routed to the Python extension, which does not by itself prove resolution. A useful tool would need to distinguish simulated shell rules from actually observed argv. Existing visualizers and process inspectors reduce the opportunity for a small new implementation. [VS Code #346482](https://github.com/microsoft/vscode/issues/346482), [VS Code #346503](https://github.com/microsoft/vscode/issues/346503), [Command Line Anatomy](https://robotsfirst.org/tool/cli-argv-parser-visualizer/), [px](https://github.com/robch/px)

**PromQL preview** addresses a report filed at 18:11:22 UTC about label-matcher set/delete operations mishandling metric names and repeated matchers. A before/after intent view could be useful, but correctness depends on current PromQL parsing. The archived PromLens project also directs users toward explanation functionality integrated into Prometheus. [Prometheus #20362](https://github.com/prometheus/prometheus/issues/20362), [PromLens](https://github.com/prometheus/promlens)

## Existing quiz alternatives

The comparison is based on reviewed READMEs and repository metadata. It is selective and does not establish that a feature is absent from every implementation.

- **course-quiz-builder** already offers an offline Node builder, per-question explanations, accessible controls, retry-wrong-only and result JSON. Those features alone provide little distinction. [Pinned README](https://github.com/the3ma/course-quiz-builder/blob/e2ac75e52a9a8214b656d9da1a505a2c74116225/README.md)
- **one-file-quiz** supports code blocks, study modes, mistake review, history and progress import/export. [Pinned README](https://github.com/lokthok/one-file-quiz/blob/abe2f54bf5368d53744d2338b6d76ecb73c7153e/README.md)
- **single-file-exam-engine** builds offline HTML from YAML/JSON and supports several question types. Its README describes local grading results that disappear on refresh. [Pinned README](https://github.com/u235xuxu/single-file-exam-engine/blob/4d28cf90bacc8a5fbce4e0732a1f2b133b4a1d16/README.md)
- **quizdown-js** supports Markdown-like quizzes with hints and explanations. Its repository is archived, with November 19, 2025 given in its README. [Pinned README](https://github.com/bonartm/quizdown-js/blob/3c831c461dcf11c0f97adfa568ac761094e0ccc9/README.md)
- **Solo Quiz Player** runs JSON assessments offline and exports attempts as CSV. [README](https://github.com/salty-flower/solo-quiz)

The proposed convenience is a small package that checks quiz-content identity and independently recomputes the result from exported choices. The reviewed READMEs above do not describe that specific verification command. Quizzes remain authored content, and authors must check the correctness of their questions and keys. A digest detects content mismatches. Editable receipts and embedded keys provide no proof of learner identity or supervised exam integrity.
